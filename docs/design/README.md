# Design exports

One folder per feature: `docs/design/F-xx/`, holding the exported Claude Design frames (HTML) listed in that PRD's front matter (`frames:`). Exported when the PRD is approved, committed before or as the first commit of the feature branch.

These files are a visual reference only: match labels, order, states and numbers. Don't import their markup or CSS into the app; build with the app's own components and tokens.
